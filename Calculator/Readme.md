  # Calculator
  <br>
  A simple calculator that helps users to simple calculations. It is built by using basic python and with the help of simple calculations
<br>
# Features
- Addition
- Subtraction
- Multiplication
- Division
- Power Finding
- Calculation History
  <br>
# Technologies Used
- Python 3 (for the program)
- VS Code (for development)
- Git & GitHub (for version control)
<br>
# How to Run
1. Install Python 3.
2. Clone the repository using the VS Code terminal.
3. Open the project in VS Code.
4. Run the calculator program.
